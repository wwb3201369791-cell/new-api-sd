# New API-SD 角色化文档中心设计

## 背景

官方 New API 文档站采用独立文档站的信息架构，将内容分为介绍、功能指南、安装部署、API 参考、AI 应用、帮助支持和合规政策；功能指南继续按用户指南和管理员指南分层。我们的仓库目前只有面向开发和验收的移动云/润元 Markdown，顶部“文档”默认仍指向官方外部站点，客户无法从自己的网关看到与实际功能、模型和渠道一致的说明。

## 目标

1. 为当前二改版本提供自己的文档中心，顶部“文档”进入我们维护的入口，不再默认跳转到官方站点。
2. 保留官方 New API 的信息层次，但只描述本版本真实支持的能力，并用 Seedance、移动云和润元的实际调用方式替换通用示例。
3. 对普通用户、Admin、Root 展示不同的导航和操作说明；用户文档与管理员文档共用基础概念和 API 参考。
4. 完整说明统一的视频任务接口、素材组/素材接口、虚拟人物/真人/音频分类、默认素材组、渠道路由和排错链路。
5. 管理员仍可通过系统设置配置外部文档地址；未配置外部地址时使用站内文档中心。

## 非目标

- 不复制官方文档原文、品牌文案或官方站点链接作为默认内容。
- 不在文档页面显示任何真实的上游视频密钥、素材 AK/SK、客户 Token 或服务器凭证。
- 不把文档可见性当作接口权限；渠道、用户、日志和系统设置权限继续由后端接口执行。
- 不在本阶段实现新的素材上传、视频生成或上游协议功能；文档只反映现有实现。

## 用户体验与路由

### 站内入口

新增公开路由 `/docs` 作为文档中心入口。页面使用文档壳层：顶部站点标题和语言入口，左侧分组导航，中间正文，右侧当前页面目录。代码块提供复制按钮，页面标题和链接可直接复制。

文档路由采用以下路径：

```text
/docs                         文档首页和快速开始
/docs/guide/user              用户指南
/docs/guide/admin             管理员指南
/docs/guide/seedance          Seedance 专题
/docs/api                     API 参考
/docs/installation            安装部署
/docs/support                 帮助与排错
/docs/policy                  合规与使用边界
```

各页面由同一文档壳层渲染，页面内容来自版本化的仓库文档数据。链接使用 TanStack Router，刷新和直接访问路径均可工作。

### 角色可见性

- 未登录用户和普通用户可查看首页、快速开始、用户指南、Seedance 专题、API 参考、安装部署、帮助和政策。
- Admin 可在上述内容之上看到管理员指南入口。
- Root 看到管理员指南中的全部系统配置、文档配置和运维章节。
- 普通用户直接访问 `/docs/guide/admin` 时显示权限提示并返回 `/docs/guide/user`，不会渲染管理员正文。
- 角色判断只影响文档导航和页面展示；所有后台操作仍由现有 API 权限中间件保护。

### 顶部“文档”链接

后端 `general_setting.docs_link` 的默认值改为 `/docs`。前端导航仅在链接是绝对的非本站 URL 时标记为外链；`/docs`、`/docs/...` 等本站路径使用应用内导航。管理员填写自定义完整 URL 后，继续按官方行为跳转到外部文档站。

## 内容架构

### 文档首页

首页提供网关定位、三步快速开始（创建 Token、确认模型、发送请求）、当前支持的渠道和 Seedance 快速入口，并明确“客户只调用 New API，后台渠道决定移动云或润元”。

### 用户指南

用户指南覆盖注册登录、概览、API Token、API 地址和认证、SDK/curl、任务与日志、额度与模型访问范围。视频部分以 `/v1/videos` 为主，补充火山方舟兼容路径、任务轮询、结果下载和 `X-OneAPI-Request-Id` 链路定位。

### Seedance 专题

Seedance 专题统一描述移动云和润元的外部请求格式，并说明网关内部完成字段、签名、状态、错误和结果 URL 映射。内容包括：

- 文生视频、图生视频、参考视频、参考音频；
- `doubao-seedance-2.0`、`/v1/models` 和模型映射；
- 视频任务创建、查询、列表、取消、制品预览和下载；
- 公网 URL 与 `asset://ASSET_ID` 的使用差异；
- 统一响应头、超时、幂等和错误码。

### 素材库专题

素材库文档明确区分两个维度：

| 维度 | 字段 | 含义 |
| --- | --- | --- |
| 人物/用途分组 | `groupType=AIGC` | 虚拟人物和普通 AI 素材 |
| 人物/用途分组 | `groupType=LivenessFace` | 真实人物，需真人认证 |
| 媒体类型 | `assetType=Image` | 图片 |
| 媒体类型 | `assetType=Video` | 视频 |
| 媒体类型 | `assetType=Audio` | 音频 |

同时说明每个客户/渠道的默认素材组、自定义素材组、归属校验、`ACTIVE` 审核状态、公网素材 URL、真人认证会话和 `asset://` 引用规则。普通 AIGC 组接口不允许伪造真人组；真人流程必须使用专用认证接口。

### 管理员指南

管理员指南沿用官方栏目顺序，但改为本项目字段和页面名称：渠道创建、视频 Bearer Key 与素材 AK/SK 分离、模型/价格/分组、路由策略、TaskPublicAddress、素材库连接测试、用户额度、日志和部署运维。敏感凭证只写“在后台渠道中保存”，示例只使用 `TOKEN`、`ACCESS_KEY` 等占位符。

### API 参考、安装、支持和政策

API 参考按 AI 模型接口与管理接口分组，优先收录当前项目已有路由；每个接口提供认证要求、请求体、成功响应、常见错误和 curl 示例。安装页面覆盖 Docker、数据目录 `/data`、HTTPS 和生产更新。帮助页面提供从客户端请求 ID 到上游请求 ID、任务 ID 的排错流程；政策页面说明上游授权、素材审核和日志审计要求。

## 内容实现

以仓库 `docs/mobilecloud-seedance.md`、`docs/mobilecloud-seedance-usage.md`、`docs/runyuan-seedance.md` 和 `docs/mobilecloud-asset-curl.md` 为事实来源，抽取为文档内容模块，避免网页正文与接口实现分叉。现有 Markdown 继续保留，作为 GitHub、运维和验收版本；网页文档增加“最后更新时间”和当前版本标记。

文档壳层的通用 UI 文案使用 i18n；正文至少提供中文内容，并为导航、权限提示、复制、搜索和错误状态提供英文键值。代码示例中的主机、Token、Key、任务 ID 和素材 ID 一律使用占位符。

## 错误与降级

- 文档内容加载失败时显示可重试的错误页，不影响 API 网关其他路由。
- 角色信息尚未加载时先显示公共文档，加载完成后再补充管理员导航。
- 管理员自定义外部文档链接为空时回退到 `/docs`；外部链接仍保持可配置。
- 文档示例中的接口状态和错误码必须与当前控制器、插件和路由一致；发现不一致时以代码为准并更新 Markdown 基线。

## 验证策略

1. 路由测试：匿名、普通用户、Admin、Root 分别访问 `/docs`、`/docs/guide/user` 和 `/docs/guide/admin`，验证导航和权限降级。
2. 导航测试：默认 `docs_link=/docs` 使用内部路由；管理员配置完整外部 URL 时标记为外链并保留原地址。
3. 文档内容测试：Seedance、素材组分类、默认素材组、真人认证、`asset://`、视频轮询和错误码关键字必须出现在对应章节。
4. 前端质量：运行受影响测试、`bun run typecheck`、相关 lint 和生产构建。
5. 后端回归：运行现有移动云/润元控制器、插件协议、路由和资产测试，确认仅改变文档入口时不影响 API 行为。

## 发布与回滚

文档页面、文档内容和入口改造作为一个提交发布；部署前保存当前镜像和数据库配置。若站内文档页面出现问题，管理员可以把 `docs_link` 临时改回外部地址，或回滚前端镜像；API、渠道和素材数据不受影响。
